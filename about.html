Quem desenvolveu este projeto

Este site foi desenvolvido por Edsom Fontes, estudante do curso de Ciência da Computação Instituto Federal do Ceará — Campus Aracati, como atividade avaliativa da disciplina.

O projeto foi construído com HTML semântico como foco principal, utilizando Vite com Vanilla JS apenas como ferramenta de build, sem uso de JavaScript no conteúdo das páginas.

Versão do projeto: 1.0 1.1 — commit no 12(aprox.).

Tecnologias utilizadas

Tecnologia Função no projeto
HTML5 Estrutura e semântica das páginas
CSS3 Estilização básica (opcional na atividade)
Vite Ferramenta de build e servidor de desenvolvimento
Git / GitHub Versionamento e hospedagem (GitHub Pages)

Recursos HTML explorados neste projeto

  • Estrutura semântica (header, nav, main, section, article, footer)
  • Imagens responsivas com picture/source
  • Mapas incorporados via iframe
  • Formulário com múltiplos tipos de input
